Each call is a cold, logged out session with no history and no personalization, with web search turned on. Engines: ChatGPT (GPT 4o), Gemini (Gemini 2.5 Flash), Claude (Claude Sonnet 4.5) and Perplexity (Sonar). Positions count every entry in the order the engine named it, firms and people together. Every person named was checked against a public source such as a firm bio, LinkedIn or press, and tagged by role. Nobody is shown as a broker without a source. Engine answers vary run to run, so treat this as a snapshot.
